reverse() {
  local input=$1 output='' i
  for (( i = ${#input} - 1; i >= 0; i-- )); do
    output+=${input:i:1}
  done
  printf '%s\n' "$output"
}

Two implementation notes worth stating rather than hiding:

- I used a character loop instead of `rev` deliberately — `rev` is from `util-linux` and is not guaranteed present, and the repo convention favors pure Bash with no external dependencies. The loop is also multibyte-correct under a UTF-8 locale, since `${#s}` and `${s:i:1}` operate on characters, not bytes.
- Multibyte correctness depends on the locale. Under `LC_ALL=C` this reverses bytes and would mangle non-ASCII input. That matches how the rest of the file behaves (`${1^^}` is likewise locale-dependent), so I did not add locale forcing — but flag it in case you want ASCII-only guarantees made explicit.
