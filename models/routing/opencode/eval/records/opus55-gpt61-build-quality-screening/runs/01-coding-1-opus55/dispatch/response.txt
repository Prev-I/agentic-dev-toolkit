## Change

**`environments/linux/install.sh`**
- **New `prepend_managed_path_dirs()`**, defined just before the bootstrap. It walks `$HOME/.opencode/bin`, `$HOME/bin`, `$HOME/.local/bin` in that order (lowest priority first). For each one it runs `[[ -d "$dir" && ":$PATH:" != *":$dir:"* ]]` and, if true, sets `PATH="$dir:$PATH"`. The quoted `$dir` is matched literally, so only a complete, exact entry counts as present. When all three are added the order is still `.local/bin`, `bin`, `.opencode/bin`, then the original PATH. If PATH starts empty, its empty entry is kept: `…/.opencode/bin:`.
- **Bootstrap:** the unconditional `export PATH=…` is replaced by a call to `prepend_managed_path_dirs`.
- **Managed Bash block:** the same loop is written inline, using a variable named `__adt_path_dir` that is unset afterwards. This way nothing extra is left behind in the user's shell. The markers, the `OPENCODE_ENABLE_EXA` line, mise and direnv activation, backup and dry-run behaviour are unchanged.
- **Refresh at the end of `ensure_shell_configuration`:** now calls `prepend_managed_path_dirs`. It runs after the existing `mkdir -p ~/.local/bin`, so `.local/bin` still gets added.
- `main "$@"` is still the last line.

**`tests/install.sh`**
- A helper, `path_after <site> <home> <path>`, returns the resulting PATH for each site:
  - **bootstrap:** sources the installer in a fresh bash process.
  - **bashrc:** sources the generated `.bashrc` with direnv stubbed out.
  - **refresh:** runs `ensure_shell_configuration` in a subshell. The commands it calls are resolved via `command -p`, so the PATH being tested can even be empty.
- Each test HOME is disposable and lives under `path guard [x]/`. The space covers paths with spaces, and the brackets make a glob-based match fail.
- Eight new tests:
  - empty PATH gives all three directories in priority order plus the kept empty entry (every site)
  - missing directories are skipped
  - existing, duplicate and empty entries are kept exactly, with no duplicates added
  - only exact entries count as present: a trailing slash, a subdirectory, a glob lookalike or a longer path ending in the same name do not
  - running again, or sourcing `.bashrc` twice, adds nothing
  - mise and direnv still activate (using a stub `mise` executable)
  - re-running keeps user content, a single pair of markers and the backup, and removes the old unconditional line
  - dry-run writes nothing and leaves PATH unchanged
