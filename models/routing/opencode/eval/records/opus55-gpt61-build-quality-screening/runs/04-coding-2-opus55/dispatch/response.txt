## Change (`environments/linux/install.sh`)
- **New function `prepend_managed_path_entries`** (around line 67). It goes through the three directories in reverse (`.opencode/bin`, `bin`, `.local/bin`) and prepends each one that exists and doesn't already appear exactly in `":$PATH:"`. Going in reverse means new directories still end up in the order `.local/bin`, `bin`, `.opencode/bin`, ahead of the original PATH. The prepend uses `$dir${PATH+:$PATH}`, which keeps the original PATH exactly as it was, so an empty PATH becomes `…/.local/bin:…/bin:…/.opencode/bin:` with the trailing empty entry.
- **Installer startup:** the old unconditional `export PATH=…` is replaced by a call to that function.
- **Managed Bash block:** it contains its own copy of the same loop, because `.bashrc` can't call installer functions. The loop variable is `__adt_path_dir` and is unset afterwards. The mise/direnv activation, `OPENCODE_ENABLE_EXA`, the block markers and the backup logic are unchanged.
- **Refresh at the end of `ensure_shell_configuration`:** now calls the function. This means a `~/.local/bin` the function just created gets added, and nothing is duplicated.
- `main "$@"` is still the last line.

**Assumptions:**
- If PATH is completely unset (not just empty), no trailing empty entry is added. The spec doesn't cover this case.
- If only some directories are already present, the missing ones are prepended in priority order and the existing entries stay where they are.

## Tests (`tests/install.sh`)
I added 7 tests. Each one checks the resulting PATH string exactly, at all three places, using a throwaway HOME that contains a space and a fixed starting PATH. Each place is tested in a separate child shell or subshell, so the suite's own PATH and the real HOME are never touched. The tests cover:
- the priority order when all three directories are new;
- an empty starting PATH;
- directories that are already present, including an existing order that must not be changed;
- near-misses that don't count as present (trailing slash, a longer name, existing duplicates, an empty entry in the middle);
- directories that don't exist;
- running it repeatedly from a normal and from an empty starting PATH;
- the markers and backup still working, and mise/direnv still activating, all checked by running them;
- dry-run leaving both `.bashrc` and PATH unchanged.
