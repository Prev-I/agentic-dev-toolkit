## What changed in `environments/linux/install.sh`
- **New helper `prepend_managed_path_directories`** (defined just before the bootstrap): it goes through `.opencode/bin`, `bin`, `.local/bin` in that order and puts each one at the front of PATH if `[[ -d dir ]]` is true and `":${PATH-}:" != *":$dir:"*`. Going through the list backwards keeps `.local/bin` → `bin` → `.opencode/bin` → original PATH when all three are added. Existing entries are never touched, so an empty PATH becomes `…/.local/bin:…/bin:…/.opencode/bin:`. The directory is quoted inside the pattern, so paths with spaces or glob characters are compared literally.
- **Bootstrap**: the unconditional `export PATH=…` is replaced by a call to the helper.
- **Managed `.bashrc` block**: the same loop is written inline, since `.bashrc` can't call installer functions. Its loop variable is `__adt_path_dir` and is unset afterwards. The block markers, `OPENCODE_ENABLE_EXA`, mise activation, direnv hook, backup and dry-run early-return are unchanged.
- **Refresh at the end of `ensure_shell_configuration`**: now calls the helper.
- `main "$@"` is still the last line.

## Tests added to `tests/install.sh`
`path_after_site` runs each case against all three sites. Every test uses a throwaway HOME whose name contains spaces:
- **Bootstrap:** the sourced function file runs under `env -i`, in a new process for each activation.
- **`.bashrc` block:** the block is generated, then sourced with `direnv` stubbed out.
- **Refresh:** `ensure_shell_configuration` runs in a subshell with its commands pre-loaded via `hash -p`, so it still works when PATH is empty.

Cases covered:
- all three added in priority order
- empty PATH keeps its empty entry
- a missing directory (or a regular file named `bin`) is skipped
- exact entries are skipped, while near-misses (`bin/`, `bin-old`), empty middle entries and existing duplicates are kept as they are
- three activations produce no duplicates
- dry-run leaves PATH, `.bashrc` and `.local` untouched
- a re-run keeps one pair of markers, keeps user content and mise activation, and backs up the original once
