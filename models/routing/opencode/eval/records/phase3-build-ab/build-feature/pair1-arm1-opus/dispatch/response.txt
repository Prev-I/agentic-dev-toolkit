reverse() {
  local s=$1 out='' i
  for (( i = ${#s} - 1; i >= 0; i-- )); do
    out+=${s:i:1}
  done
  printf '%s\n' "$out"
}

Two honest caveats on the implementation:
- It's pure-bash rather than piping to `rev`, avoiding a coreutils dependency and a subshell. Cost is O(n²) string concatenation — irrelevant for typical inputs, but not the choice I'd make for megabyte strings.
- Character reversal is per-codepoint, so it's correct for plain UTF-8 but will mangle combining marks and emoji ZWJ sequences (grapheme clusters). The tests don't cover that, and handling it properly needs more than bash. Flagging rather than silently claiming full Unicode correctness.
