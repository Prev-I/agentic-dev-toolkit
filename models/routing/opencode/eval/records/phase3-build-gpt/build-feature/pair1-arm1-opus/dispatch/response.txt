**Implementation notes:**
- Pure bash rather than the external `rev`, per the repo's Bash-only convention, and it avoids a subshell/pipeline.
- `${s:i:1}` slices by character (not byte) under a UTF-8 locale, so multibyte input reverses correctly. Note this reverses *code points*, so combining-mark sequences or emoji ZWJ clusters would still be split — out of scope for the stated requirement, but worth knowing if that input ever matters.
- `${1-}` guards against unset `$1` tripping `set -u` if the function is ever called with no argument; it prints an empty line rather than erroring. If you'd prefer a missing argument to be a hard failure, say so and I'll make it fail loudly instead.
